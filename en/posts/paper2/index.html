Overview

Relago is the crash-detection and structured reporting system developed for the Xinux distribution. It is inspired by Fedora’s ABRT but redesigned around Rust’s ownership model and NixOS’s declarative configuration principles.

Architecture

┌─────────────┐       signal       ┌─────────────────┐
│  Monitored  │ ─────────────────► │  Relago Daemon  │
│  Process    │                    │  (systemd unit) │
└─────────────┘                    └────────┬────────┘
                                            │ plugin dispatch
                             ┌──────────────┴──────────────┐
                             ▼                             ▼
                     ┌──────────────┐             ┌──────────────┐
                     │ Core Report  │             │ Custom Plugin│
                     │ (derive)     │             │ (trait impl) │
                     └──────────────┘             └──────────────┘

Derive Macro

The #[derive(CrashReport)] macro auto-generates serialisation, a human-readable summary, and a structured JSON schema:

use relago::CrashReport;

#[derive(CrashReport)]
struct SegfaultReport {
    pid:       u32,
    timestamp: u64,
    backtrace: Vec<Frame>,
    exe_path:  PathBuf,
}

Expands to (simplified):

impl CrashReport for SegfaultReport {
    fn report_name() -> &'static str { "SegfaultReport" }

    fn to_json(&self) -> serde_json::Value {
        serde_json::json!({
            "pid":       self.pid,
            "timestamp": self.timestamp,
            "backtrace": self.backtrace,
            "exe_path":  self.exe_path,
        })
    }

    fn summary(&self) -> String {
        format!("Segfault in PID {} at t={}", self.pid, self.timestamp)
    }
}

NixOS Integration

The Relago daemon ships as a NixOS module:

{ config, pkgs, ... }:
{
  services.relago = {
    enable   = true;
    plugins  = [ pkgs.relago-plugins.coredump ];
    reportTo = "https://crashes.example.com/ingest";
  };
}
