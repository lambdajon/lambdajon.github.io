GHC Generics and Scrap Your Boilerplate

2025-06-01
haskelltype theorymetaprogramming

Presentation notes for an academic audience.

Motivation

Writing boilerplate for data traversal is tedious. Two Haskell approaches solve this — GHC Generics and SYB (Scrap Your Boilerplate) — with different philosophies and tradeoffs.

GHC Generics

GHC Generics reifies the structure of a datatype at the type level using a universe of representation types:

-- The Generic class
class Generic a where
  type Rep a :: Type -> Type
  from :: a    -> Rep a x
  to   :: Rep a x -> a

-- Representation universe
data    U1        p = U1                   -- unit / no fields
newtype K1 i c    p = K1 { unK1 :: c }    -- a single field of type c
data    (:+:) f g p = L1 (f p) | R1 (g p) -- sum (|)
data    (:*:) f g p = f p :*: g p          -- product (,)

A generic toList collects all values of a given type from any Generic structure:

class GCollect f where
  gCollect :: f p -> [a]

instance GCollect U1 where
  gCollect _ = []

instance (GCollect f, GCollect g) => GCollect (f :*: g) where
  gCollect (x :*: y) = gCollect x ++ gCollect y

instance GCollect (K1 i a) where
  gCollect (K1 x) = [x]

Scrap Your Boilerplate (SYB)

SYB uses the Data typeclass and runtime type representations for generic queries and transformations:

-- Increase every Int in an arbitrary structure by 1
bumpInts :: Data a => a -> a
bumpInts = everywhere (mkT (+ 1 :: Int -> Int))

-- Collect all strings anywhere in a structure
allStrings :: Data a => a -> [String]
allStrings = everything (++) (mkQ [] (: []))

The key combinator recurses bottom-up:

everywhere :: Data a => (forall b. Data b => b -> b) -> a -> a

Comparison

Aspect GHC Generics SYB
Type safety High (compile-time) Moderate (cast)
Expressiveness Structural Any recursive traversal
Compile overhead Higher Lower
Primary use case Derived instances Generic queries
Extension point Typeclass instances mkT / mkQ

Takeaway

  • Prefer GHC Generics when deriving instances (ToJSON, NFData, …).
  • Prefer SYB for ad-hoc traversals over heterogeneous trees.
  • Template Haskell is the escape hatch when both fall short.
